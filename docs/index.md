# Grok Story Handoff

**A local handoff tool for long Grok fiction projects.**

When a Grok writing window fills up, Grok Story Handoff helps you turn the saved chat into a clean story project and a ready-to-copy prompt for the next window.

## Download

[Download the latest Windows release](https://github.com/xiaoanran0602-pixel/grok-story-handoff/releases)

## What you get

- Cleaned story canon.
- Current story bible.
- Recent continuity context.
- Next-window handoff prompt.

## Basic workflow

1. Save your Grok chat as `.mhtml` / `.mht`.
2. Put it in one story folder.
3. Open the app and select that folder.
4. Run the append or rebuild workflow.
5. Copy `handoff/03_下个窗口直接复制这个.md` into a new Grok window.
