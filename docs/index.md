# Grok Story Handoff / Grok 小说交接面包机

AI-assisted local tool for cleaning long Grok conversations and generating story handoff packs.

基于 AI 的 Grok 长对话清洗与续写交接工具。

**Input:** Grok `.mhtml` conversation  
**Output:** story canon + story bible + handoff pack
